# tauri/hh-pro

Standalone public Tauri 2 shell for the external audience (DECISIONS.md D2):
contractors and their customers, brand-forward on the `hh-pro` public brand.
The pre-auth bundles (public desk, demo entry, the audience landing pages)
live in the `hh-public` web shell family, also brand `hh-pro`; they are web
bundles, not a Tauri shell.

Camera and fine location are Field only (plan B.3); this shell's capability
file must never copy hh-field's grants, and the contractor apps hold no
device permission this profile does not name itself.
