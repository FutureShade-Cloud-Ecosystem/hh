# tauri/hh-work

Internal Tauri 2 shell for office roles (DECISIONS.md D2): Counter Till,
Quote Desk, Dispatch Board, Buying and Stock, Money Desk, Manager Home,
Dealer Admin, House Messages. Desktop and tablet. Loads role-allowed
micro-apps from `web/apps/` with the in-shell switcher and the shared
`@hardscapehouse/shell-chrome`. Utility-first on the FutureBuild tokens.

Camera and fine location are Field only (plan B.3); this shell's capability
file must never copy hh-field's grants, and the office apps hold no device
permission this profile does not name itself.
