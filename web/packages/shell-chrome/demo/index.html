@hardscapehouse/shell-chrome demo

Static page, no scripts: the shell chrome over the demo tenant's fake Field manifest (Yard Pick and Receive, HH Drive and House Messages for the yard manager), every state the package paints, at the phone and tablet widths. Rendered by Node from the element render functions themselves, each cell into its own declarative shadow root. The committed pages are the two builds: index.html (brand mode, the default) beside index-light.html, with the element sheets under demo/sheets/ travelling with them. Serve it live with npm run demo (a port in the field cycle's range, refused if taken). The model objects (the selector's groups, the rail's pins) are wired in code by a shell; this page carries their rendered output and the package's tests hold the wiring contract.
