# The await ledger of the Quote Desk app

Every asynchronous read or write in the app's `src` is on this list: every `await`, every `then()`, `catch()` and `finally()`, every timer, every
promise made by hand, and every call that is started without being waited for. Each is either GUARDED by the quote
context (or, for the settings screens and the list, by the scope, branch, profile or sequence named, and, for the pricing
panel, by the tab's own context with the record, customer, rule or break and the sequence named) or ruled SAFE for a
reason, usually that it is not tied to a quote. The pricing panel is not tied to a quote: its reads and writes are tied to
the signed in session and to the record or customer being edited, and a panel that the Pricing button has swapped away, or
a sign out, cancels its context, so a read or write still out then is dropped rather than landing on a dead element or
sending a follow-up under another session; a floor confirmation still owed is sent by the panel's seat in the sign out's
waits (PricingTabBase.flushForSignOut).

`test/await-ledger.test.mjs` is the census: it scans `src`, counts the calls per file, symbol and kind, and fails when a call
has no row here, when a count differs, or when a row names code that no longer exists. A new `await` added later fails
the test until it is ruled on this page. A symbol of `*` stands for every symbol of that file and kind without a row of
its own. The same test checks that every mutant named below exists, that its edit still applies once to the source, and
that a test with the name given exists.

How to read a row:

- **Symbol** is the method or function the call sits in. Rows are anchored by that name, never by a line number.
- **Kind** is `await`, `then`, `catch`, `finally`, `void call` (a call started with void), `floating call` (a call typed as a promise that nobody awaits and nobody voided: a bare statement, an arm of a short circuit or ternary statement, or a promise handed to another call as an argument), `promise arrow` (an arrow whose body is a promise, block bodied arrows included when they return one), `stored promise` (a promise kept in a field, a property, a local or a field initializer, by assignment or by declaration), `for await`, `setTimeout`, `setInterval` or `new Promise`. The census types the source with the TypeScript checker, so a promise is found by its type and not by its name.
- **Count** is how many calls of that kind the symbol holds.
- **GUARDED** rows name the guard. **SAFE** rows name why no quote can be touched.
- **Mutants** are the ids in `test/mutants.json`. Each is one edit that takes the guard away. `node test/run-mutants.mjs <id>`
  applies it, runs the test named in the last column and expects it RED; with no id it runs them all.
- **Tests** is the start of the title of the test that goes red without the guard.

Guards that cannot be tested deterministically: none. Two are reached only by a script, not by the screen: the profile
check after a layout save (the profile select is held while a save is out, so the test moves the profile the way a script
would) and the branch check of the policy panel (a quote's branch changes only by opening another quote, which the test
does by setting the property). The reviewers are asked to rule on whether those two stand.
