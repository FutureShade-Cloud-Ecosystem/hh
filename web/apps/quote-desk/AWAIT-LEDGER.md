# The await ledger of the Quote Desk app

Every asynchronous read or write in the app's `src` is on this list: every `await`, every `then()`, every timer, every
promise made by hand, and every call an event handler starts without waiting for it. Each is either GUARDED by the quote
context (or, for the settings screens and the list, by the scope, branch, profile or sequence named) or ruled SAFE for a
reason, usually that it is not tied to a quote.

`test/await-ledger.test.mjs` is the census: it scans `src`, counts the calls per file, symbol and kind, and fails when a call
has no row here, when a count differs, or when a row names code that no longer exists. A new `await` added later fails
the test until it is ruled on this page. A symbol of `*` stands for every symbol of that file and kind without a row of
its own. The same test checks that every mutant named below exists, that its edit still applies once to the source, and
that a test with the name given exists.

How to read a row:

- **Symbol** is the method or function the call sits in. Rows are anchored by that name, never by a line number.
- **Kind** is `await`, `then`, `void call` (a call started without waiting for it), `setTimeout`, `setInterval` or `new Promise`.
- **Count** is how many calls of that kind the symbol holds.
- **GUARDED** rows name the guard. **SAFE** rows name why no quote can be touched.
- **Mutants** are the ids in `test/mutants.json`. Each is one edit that takes the guard away. `node test/run-mutants.mjs <id>`
  applies it, runs the test named in the last column and expects it RED; with no id it runs them all.
- **Tests** is the start of the title of the test that goes red without the guard.

Guards that cannot be tested deterministically: none. Two are reached only by a script, not by the screen: the profile
check after a layout save (the profile select is held while a save is out, so the test moves the profile the way a script
would) and the branch check of the policy panel (a quote's branch changes only by opening another quote, which the test
does by setting the property). The reviewers are asked to rule on whether those two stand.
